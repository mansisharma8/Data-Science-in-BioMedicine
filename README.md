# Personalized Health and Fitness Advisor

## Overview
This project focuses on applying **Data Science in Biomedicine** to develop a **Personalized Health and Fitness Advisor**. The system leverages **machine learning and data analytics** to provide tailored health and fitness recommendations based on user profiles, activity levels, and medical conditions.

## Dataset
- **Source:** Publicly available health and fitness datasets.
- **Features:** Includes user demographics, activity tracking, dietary intake, and medical history.
- **Preprocessing:**
  - Cleaned and normalized health records.
  - Applied feature engineering to extract meaningful insights.
  - Handled missing values and ensured data integrity.

## Methodology
1. **Exploratory Data Analysis (EDA):**
   - Analyzed correlations between **lifestyle choices and health outcomes**.
   - Visualized activity patterns and nutritional habits.

2. **Predictive Modeling:**
   - Built machine learning models to predict:
     - Risk of **chronic diseases** (diabetes, hypertension, obesity).
     - Personalized **exercise and diet plans**.
   - Trained **classification and regression models**:
     - Logistic Regression
     - Random Forest
     - XGBoost

3. **Recommendation System:**
   - Implemented **collaborative filtering** for diet and fitness recommendations.
   - Integrated **NLP-based chatbot** for personalized health guidance.

4. **User Interface & Deployment:**
   - Developed a simple **web dashboard** for users to input data and receive recommendations.
   - Provided interactive **visualizations** for health progress tracking.

## Results & Insights
- Achieved **high prediction accuracy** for disease risk factors.
- Improved fitness recommendation effectiveness through personalized data-driven insights.
- Demonstrated **real-world applications** of AI in biomedicine.

## Technologies Used
- **Programming Languages:** Python
- **Libraries & Tools:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, TensorFlow
- **Machine Learning Techniques:** Classification, Regression, NLP-based Chatbot
- **Visualization:** Power BI, Streamlit dashboard
- **Deployment:** Flask API, Streamlit UI


## Future Improvements
- Integrate **wearable device data** for real-time health tracking.
- Enhance recommendations using **deep learning models**.
- Expand **NLP chatbot** capabilities for real-time fitness coaching.
